# Parameter `AntiAliasing`
Default Value: `false`

!!! Warning
    This is an **Expert Parameter**! Only change it if you understand what it does!

Use anti-aliasing when applying the `InitialRotate` angle.

Rotating an image normally introduces jagged edges, which is especially
noticeable at larger rotation angles. Enabling anti-aliasing smooths these
edges and improves recognition accuracy, at the cost of a slightly longer
processing time.
